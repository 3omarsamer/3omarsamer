## Selected projects

### 📊 [WooCommerce Analytics Dashboard](https://github.com/3omarsamer/woocommerce-analytics-dashboard-portfolio-)

A custom reporting dashboard developed after an e-commerce platform migration, when a multi-brand store needed more flexible analytics than standard reporting offered. Combines WooCommerce financial KPIs with GA4 traffic and funnel data, including reporting by category, brand, size and customer behavior.

**Focus:** WooCommerce · PHP · JavaScript · GA4 Data API · Google Cloud · HPOS-compatible reporting

### 📦 [WooCommerce Inventory Manager & Stock History](https://github.com/3omarsamer/azula-woocommerce-inventory)

Started with a real warehouse-versus-store stock discrepancy and grew into a consolidated inventory workspace. Supports SKU lookup, quantity updates, stock movement history and guided category audits — reducing repetitive navigation across WooCommerce product screens.

**Focus:** WooCommerce · Inventory workflows · SKU auditing · PHP · WordPress admin tools

### 💬 [WhatsApp Automation for WooCommerce](https://github.com/3omarsamer/azula-whatsapp-automation)

A self-hosted customer-communication automation project connecting WooCommerce order workflows with WhatsApp messaging. Built around practical order-confirmation and operations needs.

**Focus:** WooCommerce · JavaScript / Node.js · API integrations · Linux VPS · Workflow automation
